# 01 — Ядро: модель снапшота, метрики занятости, динамика, реестры

**What to build:** сквозной путь «сетка доступности → снапшот на диске →
метрики → строка сводки». Библиотека скилла (по спеке — в каталоге скилла
`glamping-occupancy`, скрипты на Python под `.venv`), которая умеет: описать
объект как «юнит/категория → дата → состояние (`free`/`busy`/`sales_not_open`/
`unknown`) + цена»; записать/прочитать датированный снапшот прогона (каталог
прогона, файл на объект, метафайл прогона); посчитать occupancy_pct по месяцам
× (все дни/будни/выходные) с исключением `sales_not_open` из знаменателя;
сравнить прогон с предыдущим (сдвиг occupancy, даты, ставшие занятыми);
прочитать/записать реестр рецептов и targets-файл. CLI-вход: скормить готовую
сетку (fixture-режим) → на диске появляется снапшот, в stdout — человеческая
строка сводки по объекту.

Схема рецепта и снапшота — из раздела Implementation Decisions спеки; это
главный шов системы, тикеты 02–06 строятся на нём, менять его после этого
тикета можно только через комментарий в этом файле.

## Комментарии

Реализация: `occupancy/` —
`occupancy_core.py` (ядро + SCHEMA-комментарий v1, шов тикетов 02–06),
`cli.py` (fixture-режим), `tests/` (24 теста внешнего поведения).

Уточнения схемы относительно спеки (зафиксированы в SCHEMA-комментарии
`occupancy_core.py`, содержательных отступлений нет):

- `unknown` тоже НЕ входит в знаменатель occupancy_pct (как и
  `sales_not_open`) и показывается отдельным счётчиком — так решено при
  постановке тикета; спека проговаривала явно только `sales_not_open`.
- Пятница отнесена к ВЫХОДНЫМ (разрез будни = пн–чт, выходные = пт–вс):
  брони загородных объектов живут уик-эндами с заезда в пятницу.
- `run.json` несёт `run_id` (дублирует имя каталога — снапшот самоописателен
  при переносе) и `schema_version: 1`.
- Fixture-режим CLI принимает объект снапшота без `checked_at`/`status`/
  `reason` — CLI дозаполняет их; пустая сетка получает
  `status: insufficient_data` с причиной.
- Отсутствующий `recipes.json` — пустой реестр (первый прогон — норма);
  отсутствующий `targets.json` — ошибка (без целей прогон не имеет смысла).
