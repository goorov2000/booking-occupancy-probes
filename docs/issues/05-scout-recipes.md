# 05 — Разведчик: находит модуль, снимает рецепт, добирает агрегаторы

**What to build:** инструкции разведки в SKILL.md скилла + первичное
наполнение реестра рецептов. Разведчик — агент с Playwright, работающий
СТРОГО последовательно (один объект за раз; гонки параллельных агентов в
одном браузере — доказанные грабли 11.08). Для объекта без рецепта или со
сломанным рецептом: найти сайт (master-table «Сайт», био Instagram,
calendars-out), открыть, найти модуль бронирования, определить движок,
снять из сетевого трафика виджета живой JSON-запрос календаря, свернуть его
в рецепт (шаблон + подстановка дат), проверить рецепт немедленным запуском
пробника и сверкой с тем, что видно на странице, записать в реестр.

Для объекта без модуля — поиск на агрегаторах (Островок, Суточно.ру,
Яндекс.Путешествия): если календарь объекта там есть, рецепт пишется с
маркировкой «квота агрегатора, не полная загрузка»; если нет — статус
no_module с причиной «бронь только в директе/телеграме» (это само по себе
факт для интервью: нет измеримого контура атрибуции).

Первичное наполнение: перегнать в реестр все известные объекты из
`calendars-out/` (19 шт.) — у кого движок известен, тем рецепты доразведать
до рабочих; собрать targets-файл топ-30 из скоринга волны 2.

Запреты: не бронировать, не сабмитить формы, капчи и антибот не обходить —
честный insufficient_data.

**Blocked by:** 01 — Ядро; 02 — Пробник TravelLine (валидация рецепта
запуском пробника хотя бы для самого частого движка).
